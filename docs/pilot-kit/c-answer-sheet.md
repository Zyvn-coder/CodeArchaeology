## Scoring reminder (facilitator's side, do not hand out)

**2** correct **and** evidenced (the evidence exists and supports the claim);
**1** correct, unevidenced; **0** wrong, or an asserted mechanism the history does
not support; **U** correctly uncertain, scored **2 only** where this question's own
"correctly uncertain" line (`d1`/`d2`) says uncertainty is the truth. A capped
answer is recorded as not answered, with the time recorded as ten. Score from the
written answer alone. Calibration = confidence − (1 if score 2 else 0).
